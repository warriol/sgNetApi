Especificaciones y restricciones estrcuturales y de datos para el ingreso de denuncias:
- "IdSGSP": es el id único que identifica y distingue una denuncia de otra, ademas es usado como clave en las demas tablas a fin de crear la relacione que una la denuncia con las demas entidades, asu vez dado el id de una entidad, se podra saber a que denuncia pertenece
- "ControlCalidad": booleando que indica si la denuncia ya fue controlada por la mesa de ayuda
- "NroFormulario": numero intenro que le da la unidad a la denuncia y se relaciona con el issgsp
- "MonedaAvalua": id que apunta a una tabla Monedas, con atributos idMoneda, abreviatura, nombre
- "MontoAvaluado": es un campo numerico que almacenara un valor de moneda con dos digitos despues de la coma, (este campo solo es obligatorio para alguno tipos de denuncia, como por ejmplo hurto, rapiñas)
- "RequiereInvestigacion": campo booleano
- "ResennaPolicial": es un string opcional
- "FechaSeguimientoAreaInvestigaciones": campo fecha opcional
- "FechaSeguimientoAreaSeguridad": campo fecha opcional

los campos mencioandos anteriormente son unicos para cada denuncia y podran modelarse en la misma tabla de denuncias
